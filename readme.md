# 快捷鍵

| 名稱 | Windows快速鍵 | Mac快速鍵     |備註|
| -------- | -------- | -------- |---|
| 自動換行 | Alt + Z | Opt + Z |
| 向下複製 | Alt + Shift + 下 | Opt + Shift + 下 |
| 向下移動 | Alt + 下 | Opt + 下 |
| 向上移動 | Alt + 上 | Opt + 上 |
| 游標直接換行 | Ctrl + Enter | Cmd + Enter |
| 多重選取 | Ctrl + D | Cmd + D |
| 單行註解 | Ctrl + / | Cmd + / |  不可使用數字鍵上的/ |
| 向右分割 | Ctrl + \ | Cmd + \ |
| 刪除列 | Ctrl + Shift + K | Cmd + Shift + K |
| 收合側邊欄 | Ctrl + B | Cmd + B |
