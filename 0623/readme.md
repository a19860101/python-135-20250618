# 格式化字串

## %

%的格式化方式參考下列表格：

| 格式化字串 | 轉換類型           |
| ---------- | ------------------ |
| %s         | 字串               |
| %d         | 10進位             |
| %x         | 16進位             |
| %o         | 8進位              |
| %f         | 浮點數             |
| %e         | 指數浮點數         |
| %g         | 10進位或指數浮點數 |
| %%         | 常值               |

| 格式化字串 | 說明                |
| ---------- | ------------------- |
| +          | 靠右對齊            |
| -          | 靠左對齊            |
| 數字       | 字串最小寬度        |
| 數字.數字  | 最小寬度.最大字元數；如果後方是f(%f)，第二個代表小數點位數 |

## format
| 格式  | 說明                   |
| :---: | ---------------------- |
|   :   | 設定格式前需要加上冒號 |
|   s   | 字串                   |
|   d   | 10進位整數             |
|   o   | 8進位                  |
|   x   | 16進位                 |
|   f   | 浮點數                 |
|  \>   | 靠右對齊               |
|   <   | 靠左對齊               |
|   ^   | 置中對齊               |
| 數字  | 字串寬度               |
| 數字.數字 | 最小寬度.最大字元數；如果後方是f，第二個代表小數點位數            |
